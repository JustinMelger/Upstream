# Artwork style references

These four approved samples define the balanced technical editorial style used by the [active artwork library](../README.md). Active generation records reference these files directly; preserve their filenames and contents.

- [Article](article.webp): annotated code review and documentation.
- [Course](course.webp): API, authentication, worker dependencies and schemas.
- [Video](video.webp): execution, requests and response timing.
- [Path](path.webp): Git commits, branches and merges.

[Original prompts and portable source filenames](generation-record.json) document their generation. Each retained WebP is 1280×720. They are style inputs, not alternative application screenshots or assignments.
