# Deferred Features

These features exist in the repository, in the roadmap, or in partial UI/backend form, but they should not define the first stable release.

## Deferred From V1

- AI Curator as a core product capability
- advanced URL metadata persistence and thumbnail pipeline work
- audience-scoped sharing
- team invitations, review requests, and discussions
- activity feed v2 behavior
- broader reliability/accessibility expansion beyond release blockers
- visual-system and motion polish work

## Experimental Or Internal

### AI Curator

The current AI curator is a deterministic draft generator and should be treated as optional or experimental for v1, not as a central product promise.

### Metadata Suggestion And Preview

The URL preview and autofill flow is useful but should be considered support tooling. It is not a core requirement for users to complete the main share flows.

## Repository Cleanup Candidates

- old or duplicate frontend route implementations that are no longer canonical
- documentation that still implies broader collaboration or richer media support than the app actually guarantees

## Release Rule

If a feature is not fully specified, tested, documented, and intentionally supported after release, it is deferred from v1 even if code exists.
